一键导入：点上方「导入 Import」选一个 .zip 插件包(内含 plugin.json + 入口文件，如 plugin.py / plugin.lua / plugin.cs)，自动装进 user_plugins/ 并启用即用，无需编译。

或手动放入 plugins/<plugin_id>/plugin.json 与入口文件。入口由清单 entry 字段决定，默认 plugin.py；平台也支持 Lua / C# / AngelScript 等多语言入口（见 MULTI_LANGUAGE_SCRIPTING 文档）。

插件可实现 on_load(ctx)、on_enable()、on_disable()、on_unload()。第三方依赖写进 requirements.txt 并 vendor 进 vendor/，用 ctx.ensure_requirements() 加载。

推荐用 @ctx.on("damage")、ctx.on_snapshot(cb)、ctx.subscribe_once(topic, cb) 监听事件；用 ctx.set_defaults({...}) 与 ctx.setting(key) 管理插件设置。
