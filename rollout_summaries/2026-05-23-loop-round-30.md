## Round 29 — `SettingsManager`

`SettingsManager` (53 lines) extracted to
`gui_modules/settings_manager.py`. Note: the actual class size
turned out to be much smaller than the early-round estimate (283
lines) — the line range between `class SettingsManager` and the
next class included a lot of unrelated module-level helpers
(`_get_icon_path`, Win32 setup, `_update_layered_win`, etc.) that
weren't part of the class.

The new module re-imports `DEFAULT_HOTKEYS` from `config` and
computes `CONFIG_FILE` relative to its own parent directory:

```python
_HERE = os.path.dirname(os.path.abspath(__file__))  # …/sao_auto/gui_modules
_SAO_AUTO_DIR = os.path.dirname(_HERE)              # …/sao_auto
CONFIG_FILE = os.path.join(_SAO_AUTO_DIR, 'settings.json')
```

This matches the original sao_gui.SettingsManager path in dev mode
(both resolve to `sao_auto/settings.json`). The docstring also
notes that this is **one of three** `SettingsManager` classes
in the codebase (sao_gui / config / sao_webview), and they
intentionally remain distinct because their APIs differ (atomic
saves, legacy-key sets, etc.).

sao_gui.py: 8439 → **8388 lines**.
