## Round 41 — `SAOPlayerGUIFisheyeMixin`

The persistent GPU fisheye overlay that runs behind the SAO menu and
floating panels. **The single biggest method extraction so far** —
`_start_fisheye_overlay` is 1078 lines on its own, the largest single
method in all of SAOPlayerGUI.

9 methods totalling 1362 lines extracted to
`gui_modules/sao_gui_fisheye_mixin.py` (1421 lines):

| Method | Lines |
| --- | --- |
| `_fisheye_close_suppressed` | 6 |
| `_release_fisheye_input_zorder` | 32 (Win32 SetWindowLongPtrW + SetWindowPos) |
| `_destroy_fisheye_hit_layer` | 10 |
| `_start_fisheye_with_retry` | 18 |
| `_any_panel_open` | 24 (utility — referenced by _maybe_stop_fisheye) |
| `_maybe_stop_fisheye` | 17 |
| **`_start_fisheye_overlay`** | **1078** (with `@_probe.decorate('ui.fisheye.start')`) |
| `_stop_fisheye_overlay` | 74 (with `@_probe.decorate('ui.fisheye.stop')`) |
| `_run_fisheye_entry` | 103 |

`_start_fisheye_overlay` builds the entire GPU rendering pipeline:
PIL ImageGrab capture → GPU/numpy distortion → HUD compositing →
BGRA bytes → GpuOverlayWindow + BgraPresenter GLFW pump at 60 fps.
Plus the transparent Tk hit layer for backdrop drag/scroll, plus
the Win32 z-order management for input transparency. All on a
background worker thread; main thread only owns the hit layer and
the start/stop control surface.

Extraction technique: a Python script identified method ranges (with
decorator preservation), wrote the mixin file, and atomically deleted
the methods from sao_gui.py. Initial run had a 1-line decorator
overlap bug between `_start_fisheye_overlay` and `_stop_fisheye_overlay`
— each was claiming the decorator line of the other. Fixed by
computing all `actual_start` indices (including decorator backwalk)
in a first pass, then using THOSE values to compute exclusive ends.

Mixin imports: `time`, `perf_probe.probe as _probe` (for the two
`@_probe.decorate(...)` decorators). Other deps (`ctypes`, `PIL`,
`gpu_overlay_window`, `threading`, `numpy`) are inline-imported
inside the methods — the existing pattern.

sao_gui.py: 6943 → 5582 (-1361).
