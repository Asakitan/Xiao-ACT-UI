# Loop round 81 — runtime-crash bug fixes (v3.2.18)

**Date**: 2026-05-24
**Rounds covered**: 79–80 (user-driven runtime crash report)
**Version**: 3.2.17 → 3.2.18

## Trigger

User ran `python main.py` and hit two real NameError crashes the prior AST audit had missed:

```
File "gui_modules/sao_gui_status_updater_mixin.py", line 228, in _get_update_view
    label_text = f"{APP_VERSION_LABEL}"
NameError: name 'APP_VERSION_LABEL' is not defined

File "gui_modules/sao_gui_link_animation_mixin.py", line 310, in _draw_entry_overlay
    eased = ease_out(t)
NameError: name 'ease_out' is not defined
```

User feedback verbatim: **"修一下bug，全是bug，你自己跑起来运行一下"**

## Root cause

Round 73's AST audit only flagged names beginning with `_` or uppercase — it
intentionally skipped lowercase plain-name calls to keep false-positive noise
down. That heuristic missed all the helper functions (`ease_out`, `lerp`,
`play_sound`, `time.time`, `math.*`, `np.*`) and any module-level constants
that happened to be UPPERCASE but were forgotten in the `from config import …`
line (`APP_VERSION_LABEL`).

## Fix

Re-ran AST audit with an aggressive predicate (any `Name` node in `Load`
context that isn't a builtin, isn't defined in the file, and isn't a known
self/cls attribute). Found additional missing imports in **7 mixins**:

| File | Imports added |
|------|---------------|
| `sao_gui_status_updater_mixin.py` | `time`, `APP_VERSION_LABEL`, `SAODialog` |
| `sao_gui_link_animation_mixin.py` | `math`, `numpy as np`, `Image`, `ImageTk`, `get_sao_font`, `ease_out`, `ease_in_out`, `lerp` |
| `sao_gui_lifecycle_mixin.py` | `time`, `play_sound`, `ease_out`, `ease_in_out` |
| `sao_gui_float_hp_mixin.py` | `_CY_UI`, `ease_out` |
| `sao_gui_float_handlers_mixin.py` | `time` |
| `sao_gui_fisheye_mixin.py` | `threading`, `tkinter as tk`, `gpu_capture` helpers |
| `sao_gui_misc_mixin.py` | `List`, `_CY_UI`, `get_skill_slot_rects`, `play_sound` |

## Verification

- `python -c "import sao_gui; print(__name__) for each"` — every imported name
  resolves (e.g. `APP_VERSION_LABEL: v3.2.17`, `ease_out: ease_out`).
- `python main.py` run for 25 s — all overlays initialized cleanly
  (DPS / BossHP / PlayerHP / Alert / SkillFX / BuffMon), packet capture
  active, no NameError anywhere in the trace.
- The `pynput Thread-3 ctypes.ArgumentError` in the log is a pre-existing
  Python-3.11 / pynput library bug unrelated to the refactor.
