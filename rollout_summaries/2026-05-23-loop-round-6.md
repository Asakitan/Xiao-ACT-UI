## Round 3 post-cadence (already shipped this loop, not yet committed)

- Added `bgr_color_match_column_ratio` to `_sao_cy_pixels.pyx` — single
  nogil pass over the BGR image producing per-column match ratio + overall

  recognition tick.

## Round 4 — `_row_independent_pct` cython migration

- Added three helpers to `_sao_cy_pixels.pyx`:
  - `_row_subpixel_crossing` — nogil clone of
    `recognition._subpixel_threshold_crossing` so the per-row scan can
    stay GIL-released.
  - `_quickselect_median` — partial-sort O(n) median for the per-row pct
    buffer (no full sort required).
  - `row_independent_fill_pct(val, sat, hue_mask, threshold)` — the main
    entry. Builds the per-row score (mask scaling + 3-wide moving-average
    convolution), walks right-to-left for the last-filled column,
    interpolates sub-pixel, and runs quickselect over the kept rows. All
    inside a single `with nogil:` block.
- Wired `recognition._row_independent_pct` as a thin wrapper that
  ascontiguous-converts val/sat to float32 and delegates to the kernel.
- **15x speedup** (0.224 ms → 0.015 ms per call for a 14×480 bar with 14
  rows kept). Parity within 0.5% absolute (worst case 0.0008 from the
  float32→float64 numerical-precision lift). 8/8 parity cases pass
  including `h<2` and `w<=4` None-return contracts.

## Round 5 — `_gradient_edge_pct` cython migration

- Added `gradient_edge_pct(smooth_score, eff_w, dynamic_range)` to
  `_sao_cy_pixels.pyx`. In one nogil pass it:
  1. Computes the discrete derivative `grad[i] = ss[i+1] - ss[i]`.
  2. Runs a 7-wide moving-average smoothing (matching
     `np.convolve(grad, ones(7)/7, mode='same')` semantics including
     zero-padded edges).
  3. Finds argmin inside the `[s_start, s_end)` search window
     (`s_start = max(2, int(eff_w*0.03))`,
     `s_end   = max(s_start+4, eff_w - 1 - max(3, int(eff_w*0.02)))`).
  4. Walks a narrow window around the minimum for the mid-score
     crossing and returns the clamped sub-pixel pct, or `None` when
     no edge stands out.
- Wired `recognition._gradient_edge_pct` to delegate.
- **~4.3x speedup** (0.0073 ms → 0.0017 ms per call for a 480-wide bar).
  7/7 parity cases EXACT (delta=0.0) — the algorithm is integer-index
  based after the convolution so the float-precision lift doesn't move
  the argmin or the final pct.
