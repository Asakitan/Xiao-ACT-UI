## Round 43 — `SAOPlayerGUIActionsMixin`

AutoKey + BossRaid have nearly identical shape:
1. `_toggle_{X}_panel` — open the quick configuration panel.
2. `_toggle_{X}_detail_panel` — open the full profile editor.
3. `_toggle_{X}` — toggle the engine on/off.
4. `_{X}_settings_ref` — settings-bag shim.
5. `_{X}_author_snapshot` — author-info for save metadata.
6. `_load_{X}_config` / `_save_{X}_config` — config IO via the engine
   module's helpers.

So they ride together in `gui_modules/sao_gui_actions_mixin.py`
(214 lines including imports + class docstring + the 17 method
bodies):

| AutoKey (9) | `_toggle_autokey_panel`, `_toggle_autokey_detail_panel`, `_toggle_auto_script`, `_auto_key_settings_ref`, `_auto_key_author_snapshot`, `_load_auto_key_config`, `_save_auto_key_config`, `_load_autokey_burst_actions`, `_save_autokey_burst_actions` |
| BossRaid (8) | `_toggle_bossraid_panel`, `_toggle_bossraid_detail_panel`, `_toggle_boss_raid`, `_boss_raid_next_phase`, `_boss_raid_settings_ref`, `_boss_raid_author_snapshot`, `_load_boss_raid_config`, `_save_boss_raid_config` |

## Round 44 — `SAOPlayerGUIEngineTogglesMixin`

Two more engine-on/off clusters that share the same toggle + refresh
pattern but DON'T overlap with AutoKey/BossRaid (different engines,
different config schemas):

**HideSeek** (auto hide-and-seek, 6 methods, ~85 lines):
* `_toggle_hide_seek` — top-level on/off
* `_start_hide_seek` — instantiates `HideSeekEngine` + `WindowLocator`,
  shows persistent AlertOverlay, schedules refresh
* `_stop_hide_seek` — engine stop + alert cleanup
* `_on_hide_seek_status` — engine status callback (debug logs only)
* `_schedule_hide_seek_alert_refresh` — schedules 50 s refresh tick
* `_refresh_hide_seek_alert` — refresh worker (re-shows the alert)

**Burst** (burst-skill trigger detection, 5 methods, ~43 lines):
* `_pick_burst_trigger_slot` — cython state-machine delegate
  (`_CY_UI.pick_burst_trigger_slot`)
* `_normalize_watched_skill_slots` — cython delegate
* `_reset_burst_tracking_state` — clears `_last_burst_*` caches
* `_toggle_burst_enabled` — toggles `burst_enabled` setting
* `_toggle_burst_slot` — adds/removes a slot from
  `watched_skill_slots` (preserves invariant: ≥ 1 slot remains)

Mixin total: 175 lines (including imports + docstring + 11 method
bodies). Module-level imports: just `_sao_cy_uihelpers as _CY_UI`
— HideSeek dependencies (`HideSeekEngine`, `WindowLocator`) are
inline-imported inside `_start_hide_seek` (matches existing pattern).

sao_gui.py: 5430 → 5303 (-127).
