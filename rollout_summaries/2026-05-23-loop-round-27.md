# /loop round-27 cadence summary — 2026-05-23

First cadence MD of the **new /loop task** focused on sao_gui structural
refactor. The previous sao_gui task (rounds 19-24) shipped two
cadence commits (`8d4fd38` v3.1.8, `4e03963` v3.1.9) covering main-
thread reductions but kept sao_gui.py as a single 9697-line monolith.
The user then asked for a structural refactor at round 25:

> 我给你说了重构sao_gui，现在一旦重战斗就会卡。能不放主线程上的就不放主线程上，用文件夹来把所有的文件归类，包括以前的文件，最好归类导入入口那些也要全部修好。不要让他9000行了，你自己看着怎么修自迭代

The minor-version bump (3.1.9 → **3.2.0**) signals the start of the
structural refactor — splitting a monolith into a package is a more
visible change than the patch-level optimization commits before it.

## Round 25 — folder + SAOHotkeyManager extracted

- Created `gui_modules/` directory with `__init__.py` that re-exports
  extracted symbols. This keeps `from sao_gui import SAOHotkeyManager`
  working while letting `from gui_modules.sao_hotkey_manager import
  SAOHotkeyManager` also work.
- Moved `SAOHotkeyManager` (75 lines) verbatim to
  `gui_modules/sao_hotkey_manager.py`. The new module re-imports
  `DEFAULT_HOTKEYS` from `config` and the optional `pynput` keyboard
  hook itself, so it's self-contained. The `settings` constructor
  argument is duck-typed (the original class never depended on the
  concrete `SettingsManager` type).
- Replaced the class definition in sao_gui.py with `from gui_modules.
  sao_hotkey_manager import SAOHotkeyManager  # noqa: E402`.

## Round 26 — `SAOSessionPlayersPanel` extracted (biggest single win)

- Moved `SAOSessionPlayersPanel` (598 lines) to `gui_modules/sao_
  session_players_panel.py`. The class manages the SAO menu's "本次
  登录玩家" left-stack list; it's GPU-painted via
  `sao_left_info_gpu.SessionPlayersGpuPainter` when available.
- Two module-level helpers used only by this class were moved
  alongside it:
  - `_SESSION_WHEEL_ROOTS: Dict[int, Dict[str, Any]]` — per-root
    panel registry keyed by `id(root)`.
  - `_dispatch_session_wheel(root, event)` — global mousewheel
    dispatcher used by `bind_global_wheel_fallback`.
- Updated `gui_modules/__init__.py` to also re-export
  `SAOSessionPlayersPanel`.
- sao_gui.py: **9682 → 9091 lines (-591 net)**. Finally close to the
  9000-line target the user set; the next extraction (`SAOPlayerPanel`,
  471 lines) will comfortably push it under 9000.
