### Initial NameError, fixed

The mixin's first compile failed:

```
NameError: name '_probe' is not defined
  File "gui_modules/sao_gui_float_hp_mixin.py", line 170, in
        SAOPlayerGUIFloatHpMixin
    @_probe.decorate('ui.panel_float.tick')
     ^^^^^^
```

`_panel_float_shared_tick` carried a `@_probe.decorate(...)`
decorator that depends on the module-level `_probe` import. Fixed
by adding `from perf_probe import probe as _probe` to the mixin's
imports — the same fix pattern used by other mixins that carried
`@_probe.decorate` decorators.
