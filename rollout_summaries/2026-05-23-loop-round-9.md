## Round 7 — 5-wide moving-average smoothing

- Added `box_convolve5_same_f32` to `_sao_cy_pixels.pyx`. Hand-written
  5-neighbour summation with double-precision accumulation, cast to
  float32 on write. Matches `np.convolve(arr, ones(5)/5, mode='same')`
  for any input length ≥ 5 (the only case `_detect_bar_pct` reaches,
  since the function returns early at `eff_w <= 4`).
- Wired BOTH convolve sites:
  - `smooth_score = np.convolve(col_score, smooth_kernel, mode='same')`
  - `smooth_hue   = np.convolve(hue_coverage, smooth_kernel, mode='same')`
- 10 parity cases at n ∈ {5..1000} match numpy to within float32
  quantization (max diff 1.2e-7).
- **~3x speedup** (2.48 → 0.80 µs/call). Both convolutions run per
  recognition tick per bar.

## Round 8 — Threshold scan and combined col_score

Two related kernels landed in the same round.

### Round 8a — `find_last_above_threshold_f32`

- Drop-in for the rightmost-above-threshold scan used by Method 3 in
  `_detect_bar_pct`:
  ```python
  filled = smooth_score >= threshold
  if filled.size >= 3:
      filled[1:-1] = filled[1:-1] | (filled[:-2] & filled[2:])
  if not np.any(filled):
      threshold_pct = 0.0
  else:
      last_idx = int(np.max(np.where(filled)[0]))
  ```
- The "single-pixel-fill repair" was proven redundant for finding the
  rightmost True: it can only flip interior `0→1` cells, and flipping
  any cell `i > last_filled` requires `filled[i+1]` to already be True
  (which would make `last_filled` ≥ `i+1` — contradiction). The cython
  kernel walks right-to-left until the first `≥ threshold` element and
  returns its index, or `-1`.
- **~27x speedup** (5.67 → 0.21 µs/call). 50 random parity cases plus
  4 hand-built edge cases pass.

### Round 8b — `compute_bar_col_score_f32`

- Folds eight chained numpy operations into one nogil pass:
  ```python
  hue_delta = np.abs(mean_hue - fill_hue_ref)
  hue_delta = np.minimum(hue_delta, 180.0 - hue_delta)
  hue_bonus = 1.0 - np.clip(hue_delta / 24.0, 0.0, 1.0)
  col_score = 0.78 * (mean_val / 255.0) + 0.22 * (mean_sat / 255.0)
  col_score = np.where(hue_coverage >= 0.12, col_score,
                       col_score * (0.72 + 0.18 * hue_bonus))
  ```
- Eliminates ~7 temporary float32 arrays of length eff_w per bar.
- **~7.3x speedup** (13.02 → 1.79 µs/call). Parity to within float32
  quantization on all five test sizes.
