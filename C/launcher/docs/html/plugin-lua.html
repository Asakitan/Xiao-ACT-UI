01

LUA 5.4

Lua 插件 API

每个插件有独立 Lua 5.4 state；入口 plugin.lua 在受控模块环境中运行。普通 ctx 方法使用冒号调用，ctx.ui builder 使用点号。

{"id":"my_lua_plugin","name":"Lua 示例","version":"1.0.0",
 "language":"lua","entry":"plugin.lua","enabled":false,
 "permissions":[]}

定义 on_load(ctx)、on_enable(ctx)、on_disable(ctx)、on_unload(ctx)。停用与卸载时撤销保存的计时器及外部资源。清单还可声明 settings_schema、capabilities、locales；require 和 ctx.engine 分别受权限门控。

03

QUICK START

面板 + 菜单 + 计时器

local ctx_ref, count, timer = nil, 0, ""
local function stop_timer()
  if timer ~= "" then ctx_ref:clear_timer(timer); timer = "" end
end
local function add()
  count = count + 1
  ctx_ref:request_redraw("demo", "count_changed")
  return {ok = true}
end
function on_load(ctx)
  ctx_ref = ctx
  ctx:register_ui_panel("demo", {title = "Lua 示例"}, render_panel, on_action)
  ctx:register_menu_category("Lua 示例", "L", function()
    return {{id="open", action_id="demo.open", label="打开面板",
      command=function() ctx:open_window("demo", 520, 360); return {ok=true} end}}
  end, 40.0)
  timer = ctx:set_interval(add, 2.0)
end
function render_panel(payload)
  return ctx_ref.ui.panel("Lua 示例", {
    ctx_ref.ui.section("状态", {ctx_ref.ui.kv("次数", tostring(count)),
      ctx_ref.ui.button("增加", "add", "primary")})})
end
function on_action(action_id, payload)
  if action_id == "add" then return add() end
  return {ok = false}
end
function on_disable(ctx) stop_timer() end
function on_unload(ctx) stop_timer(); ctx_ref = nil end

活动完整示例：plugins/example_lua_plugin/plugin.lua。

04

ENGINE

引擎与模块约束

反射面要求清单 permissions: ["engine_access"]（或 unsafe）；ctx.engine.list() 查询目录，ctx.engine.mem_read_u64(address) 等命名调用按目录参数顺序，ctx:engine_call("mem.read_u64", {address=address}) 走 raw 名称入口。ctx.engine.on(channel, fn) 注册回调；provider 不可用时原样上报错误。

require 需同名权限；只从插件根内受控的 engine/、libs/、vendor/ 等路径加载文本 Lua。跨语言 helper 只返回有界 JSON-compatible 值与函数代理。overlay 同 surface 更新事务替换，普通 ctx/action JSON 预算与专用 8 MiB overlay 文档预算不同。

05

FULL LUA SURFACE

全部 Lua ctx 接口

普通方法按 ctx:method(...) 调用（宿主兼容部分点号调用）；ctx.ui.method(...) 和 ctx.engine.method(...) 使用点号。全宿主 ctx 对照、全部 22 个 UI 构造器、126 个反射条目提供按序参数与结果字段。

名称入参、结果与用法
plugin_id, path, should_stop, ui, engine只读属性/子表；未绑定的属性返回 nil。ui 是节点构造器表；engine 是命名反射函数表。
log(msg)、time()日志与 epoch 秒数。
set_defaults(table)、get_setting(key,default) / setting(...)、set_setting(key,value)缺省设置、读取与写入；setting 与 get_setting 同义。
subscribe(topic,fn)、subscribe_once(topic,fn)、unsubscribe(token)注册持续/一次性事件回调和取消；保留数值 token；回调接收事件 payload。
emit(topic,payload) / publish(topic,payload)发布事件；缺 payload 序列化为 null。
get_snapshot()、snapshot_value(path,default)、recent_events(limit=64,topic="")读当前状态、点路径值和事件数组；Lua 未注册根 on()，用 subscribe。
register_ui_panel(id,meta,render,on_action)、request_redraw(surface,reason)render(payload) 返回 UI builder 节点；on_action(action_id,payload) 返回动作结果。request_redraw 请求刷新。
register_menu_category(name,icon,builder,priority)、register_menu_surface(id,descriptor,priority)、register_action_handler(fn)原生 Entity/插件栏回调；菜单行包含 id、label、action_id，可有 command 回调、keep_menu_open。
register_render_hook(surface,fn,priority)、unregister_render_hook(token)渲染 hook 注册/注销，priority 缺省 0；按 plugin generation 维护回调。
set_overlay(surface,spec)、clear_overlay(surface)surface-keyed、代际所有权 overlay；spec 使用专用 8 MiB JSON 预算，替换失败保留旧帧。
register_hotkey(id,callback,default_key,label)、unregister_hotkey(id)快捷键注册与注销；清单必须具备宿主要求的 hotkey 权限。
set_interval(callback,seconds)、set_timeout(callback,seconds)、clear_timer(token)周期/单次定时器返回字符串 token，clear_timer 接收该字符串；秒数须为有限正数，停用时清理 token。
notify(title,message,duration_s,kind)、toast(message)、dismiss_notify()通知、短提示与撤销，duration 缺省 60 秒，kind 缺省 plugin。
register_engine(name,engine)、get_engine(name)插件内引擎注册和查找；需 engine_access 权限或宿主允许的 unsafe 权限。
engine_call(name,args)、engine.list()、engine.on(channel,fn)、engine.<group_method>(...)raw 分发、查询当前目录、注册回调、命名调用；mem.read_u64 映射为 ctx.engine.mem_read_u64(address)；需要 engine_access，provider 缺失抛 Lua error。
open_file(filters,title,initial_dir,hwnd)、open_window(panel_id,width,height)文件选择和打开面板；文件选择取消返回空值/空路径，先检查返回。
load_local(path)、ensure_requirements(install)根内 helper 与依赖报告；require 与 load_local 是两套入口，前者受 require 权限限制。
create_compositor_layer(name,w,h,…)、upload_compositor_frame(name,bytes,w,h)、set_compositor_layer_position(name,x,y)、set_compositor_layer_visible(name,visible)、set_compositor_layer_input(name,…)、destroy_compositor_layer(name)创建图层、上传帧、控制位置/显隐/输入和销毁；功能仍需 compositor provider。
set_compositor_layer_mmf_source(name,mmf)、set_compositor_layer_shared_texture_source(name,handle,w,h)、compositor_gpu_interop_available()、compositor_layer_shared_texture_active(name)共享帧源绑定与 GPU 能力/激活状态查询。
