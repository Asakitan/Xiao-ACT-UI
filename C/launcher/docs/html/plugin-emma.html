01

EMMA

Emma 插件 API

内置原生解释器，无需额外语言运行库。使用 fn … end、let、{key: value}、.. 拼接字符串；不是 Python 方言。

{"id":"my_emma_plugin","name":"Emma 示例","version":"1.0.0",
 "language":"emma","entry":"plugin.emma","enabled":false,
 "permissions":[]}

定义 fn on_load(ctx) … end、on_enable()、on_disable()、on_unload()。on_disable() 显式返回 false 表示清理未完成，宿主保留状态以便重试；on_unload() 可否决卸载。

03

QUICK START

面板 + Entity 菜单

let count = 0
fn open_panel()
    ctx.open_window("demo", 520, 360)
    return {ok: true}
end
fn build_menu()
    return [{id: "open", action_id: "demo.open",
             label: "打开面板", command: open_panel}]
end
fn on_load(ctx)
    ctx.set_defaults({greeting: "你好"})
    ctx.register_ui_panel("demo", {title: "Emma 示例"},
        render_panel, on_panel_action)
    ctx.register_menu_category("Emma 示例", "E", build_menu, 40.0)
end
fn render_panel(payload)
    return ctx.ui.panel("Emma 示例", [
        ctx.ui.section("状态", [ctx.ui.kv("次数", tostring(count)),
            ctx.ui.button("增加", "add", "primary")])])
end
fn on_panel_action(action_id, payload)
    if action_id == "add"
        count = count + 1
        ctx.request_redraw("demo", "count_changed")
        return {ok: true}
    end
    return {ok: false}
end
fn on_unload()
    ctx.log("Emma 插件卸载")
end

带定时器、通知与动作路由的完整示例：plugins/example_emma_plugin/plugin.emma。

04

ENGINE & LIMITS

引擎与边界

ctx.engine.mem_read_u64(address) 等命名 callable 按引擎目录参数顺序分发；ctx.engine_call("mem.read_u64", {address: address}) 返回包含 status、result 的 envelope；ctx.engine.on(channel, callback) 为回调通道。功能取决于当前 provider，可通过 ctx.engine.list() 查询。

容器支持 list 的 append/extend/pop 等、dict 的 get/keys/items/update 等；string 大小写转换限 ASCII。外部 .py helper 经共享 pymini→CPython 路由，只传有界 JSON-compatible 值与 callable。普通 ctx/action JSON 与 overlay 专用 8 MiB 文档预算不同；重复设置同一 surface 只在新帧提交后替换旧画面。

05

FULL EMMA SURFACE

全部 Emma ctx 接口

Emma 根 ctx 是字典，方法以 ctx.name(...) 调用；失败通常抛 Emma 异常，保存的 token 须在停用/卸载时清理。22 个 UI builder 和 126 个引擎目录项共有完整参数与结果表。

名称参数、返回与语义
plugin_id,path,web_path,assets_path,ui,event_bus,engine字符串路径/ID 与 UI、事件、引擎字典；ctx.should_stop() 查询停止状态，ctx.time() 返回 epoch 秒。
log(value…)、set_defaults(map)、get_setting(key,default) / setting(...)、set_setting(key,value)日志、设置默认值、读取和写入；get_setting 在值不存在时使用传入 default。
subscribe(topic,fn)、subscribe_once(topic,fn)、unsubscribe(token)、emit(topic,payload)返回数值订阅 token；callback 收 payload；unsubscribe 取消后返回 bool；未提供 payload 时发 null。
on(topic,fn)、on_damage/on_heal/on_skill/on_boss/on_snapshot/on_encounter_finalized(fn)事件快捷订阅；on 可返回装饰器，提供 fn 时返回原 fn；on_snapshot 对应 act_snapshot 主题。
get_snapshot()、snapshot_value(path,default)、recent_events(limit=20,topic="")状态快照、点路径取值、最近事件数组；ctx.event_bus 复用 subscribe/subscribe_once/unsubscribe/emit 和上述 snapshot 方法。
register_ui_panel(id,metadata,render,on_action)、request_redraw(surface,reason)注册回调与重绘。render(payload) 返回 UI 节点，action(action_id,payload) 返回 {ok: true/false} 等动作结果。
register_menu_category(name,icon,builder,priority)、register_menu_surface(id,descriptor,priority)、register_action_handler(fn)Entity 菜单、surface 和 action callback；builder 返回行数组，菜单更新可重建。
register_render_hook(surface,fn,priority)、unregister_render_hook(token)渲染 hook 的绑定/解除；回调生命周期绑定插件。
register_hotkey(id,fn,default_key,label)、unregister_hotkey(id)热键注册返回 ID；注销成功/无账目分别返回 true/false。
set_interval(fn,seconds)、set_timeout(fn,seconds)、clear_timer(token)周期/单次 timer 返回字符串 token；clear_timer 对不存在的台账返回 false。
notify(title,msg,duration_s=60,kind="plugin")、toast(msg)、dismiss_notify()通知、短消息和解除通知；错误时异常。
set_overlay(surface,spec)、clear_overlay(surface)设置/移除 owner surface；同键重复提交保留一份资源账目，失败保持前帧；成功 clear 清同键记录。
register_parser_adapter/register_exporter/register_formatter/register_trigger_type/register_report_view/register_timer(id,metadata)注册六类扩展描述符；与 set_interval timer callback 不是同一接口。
register_data_source(id,metadata,start,stop)数据源及启停回调；回调失败返回 status 后资源仍按 owner 生命周期收敛。
register_engine(name,engine)、get_engine(name)、require_engine(name)插件局部引擎注册/查找/必需查找；ctx.engine 另含 get/require/register/has/list/on 与目录命名函数。
engine_call(name,args)、engine.<group_method>(...)raw 方法返回完整 {status,result}；命名调用解包 result 并处理非零 status；ctx.engine.on(channel,fn) 管理回调。
load_local(relative_path)、load_script、ensure_requirements(install)受控 helper、语言全局 load_script 在 ctx 上的兼容投影、需求报告；非模块资源返回路径，跨语言仅 JSON 值/callable。
register_thread(fn)、run_on_ui(fn)register_thread 只校验 callable 后返回 true，不启动线程；run_on_ui 转一次性 timer，非独立 UI dispatch。
open_file(filters,title,initial_dir,hwnd)、open_window(panel_id,w,h)文件选择与打开已注册面板。
create_compositor_layer(name,w,h,…)、upload_compositor_frame(name,data,w,h)、set_compositor_layer_position(name,x,y)、set_compositor_layer_visible(name,visible)、set_compositor_layer_input(name,…)、destroy_compositor_layer(name)原生图层生命周期和帧、输入配置；需相应 compositor 能力。
set_compositor_layer_mmf_source(name,mmf)、set_compositor_layer_shared_texture_source(name,handle,w,h)、compositor_gpu_interop_available()、compositor_layer_shared_texture_active(name)共享源绑定和 GPU 能力查询；handle 为零可清除来源，非零须配正宽高。
