01

PYTHON

Python 插件 API

同一种 language: "python"，两条执行路径：原生 C++ 子集 pymini 和隔离 CPython。以实际插件入口及 manifest 为准，不把子集当成完整 Python。

pymini

py_runtime: "pymini"；无需 Python DLL，支持已实现的同步语法和标准库子集。生成器为有界 eager 执行，async/await 不提供真正的异步调度。

CPython

py_runtime: "cpython"；需要可用的 plugins.python_home 与 CPython 3.11+。适合第三方库及 pymini 不支持的语法；运行库按需初始化。

auto 先无执行预检 pymini，明确不支持时才尝试 CPython；实际执行失败不会重新运行插件。

02

PLUGIN PACKAGE

清单与生命周期

在 plugins/<id>/ 放置 plugin.json 和入口文件；用户在插件管理中启用。可选 permissions、capabilities、settings_schema、locales 由清单声明；翻译元数据不会自动翻译脚本文字。

{"id":"my_python_plugin","name":"Python 示例","version":"1.0.0",
 "language":"python","entry":"plugin.py","py_runtime":"cpython",
 "enabled":false,"permissions":[]}

入口 hook 为 on_load(ctx)、on_enable()、on_disable()、on_unload()；在停用/卸载时清理自己保存的计时器、订阅和外部资源。宿主负责已注册回调的最终退役。

03

CONTEXT

ctx 方法速查

用途调用
状态与设置ctx.log(message)、ctx.set_defaults(dict)、ctx.get_setting(key, default)、ctx.set_setting(key, value)
面板与交互ctx.register_ui_panel(id, metadata, render, on_action)、ctx.open_window(id, width, height)、ctx.request_redraw(id)；回调返回 ctx.ui.panel/section/row/kv/button 构造的声明式节点
菜单与快捷键ctx.register_menu_category(title, icon, builder, priority)、ctx.register_action_handler(callback)、ctx.register_hotkey(id, callback, key, label)
事件与通知ctx.subscribe(topic, callback)、ctx.emit(topic, payload)、ctx.notify(title, message, duration_s)
计时与画面ctx.set_interval(callback, seconds)、ctx.clear_timer(token)、ctx.set_overlay(surface, spec)、ctx.clear_overlay(surface)
模块与引擎ctx.load_local(path)、ctx.engine_call(name, args)；pymini 还提供 ctx.engine.list() / 目录命名调用

回调及 ctx 都属于插件当前代，别在卸载后复用。Entity 菜单 builder 返回含 id、action_id、label 的行，command 可直接绑定回调。

04

QUICK START

面板 + 动作示例

_ctx = None
count = 0

def on_load(ctx):
    global _ctx
    _ctx = ctx
    ctx.set_defaults({"greeting": "你好"})
    ctx.register_ui_panel("demo", {"title": "Python 示例"}, render_panel, on_action)
    ctx.register_menu_category("Python 示例", "P", lambda: [
        {"id": "open", "action_id": "demo.open", "label": "打开面板",
         "command": lambda: ctx.open_window("demo", 520, 360)}
    ], 40.0)

def render_panel(payload):
    return _ctx.ui.panel("Python 示例", [
        _ctx.ui.section("状态", [
            _ctx.ui.kv("次数", str(count)),
            _ctx.ui.button("增加", "add", "primary")])])

def on_action(action_id, payload):
    global count
    if action_id == "add":
        count += 1
        _ctx.request_redraw("demo")
        return {"ok": True}
    return {"ok": False}

def on_unload():
    pass

更完整的原生示例在源码 sao_auto/C/plugins/examples/example_python_plugin/；活动插件中可参考 plugins/goose_goose_duck/ 与 plugins/Razorworks/ 的不同运行模式。

05

ENGINE & LIMITS

引擎与资源边界

反射目录的 全部 126 项与顺序参数包括 mem.*、net.*、ui.*、gpu_hunt.*、vt.* 和 config/event 组。pymini 的 ctx.engine.list() 可查询 available；CPython 不提供该目录列表或独立目录子对象，只能使用 ctx.engine_call(name, args)。二进制值使用 *_b64；provider 不可用时按状态处理。

CPython 的 engine_call(name, args) 成功返回解包的 result，status 非零抛异常，也不提供反射回调 facade；pymini 的 ctx.engine 包含 get/call/require/register/list/on 与各目录命名方法，ctx.mem 是 mem.* 别名。set_overlay 同 surface 替换在新帧提交前保留旧帧，clear_overlay(surface) 要指定 surface。反射 mem.read 单次原始长度不超过 6 MiB − 768 B，结果 JSON 限 8 MiB；大块数据分段读取。跨语言 load_local 只传有界 JSON 值与 callable，不传任意 Python 对象或 bytes。

06

FULL SURFACE

全部 Python ctx 接口

标记 C = CPython、P = pymini；两条路径的同名 API 可有不同类型与错误处理。各接口的跨语言适用范围、22 个 ctx.ui 构造器及 126 个反射项在 公共接口全集。

方法 / 属性模式、签名与使用
plugin_id, path, base_dir, web_path, assets_path, should_stop, ownerC：只读属性，另有 get_plugin_id()、get_base_dir()；owner 可写 namespace，should_stop 是只读停止状态。P：除 base_dir 外的路径/身份属性，should_stop 是可调用查询，owner 为 ID。
ui, engine, mem, event_busC：ui 提供全部 22 builder；engine 为 ctx 自身，mem 为空字典，无 event_bus。P：ui、engine、mem、event_bus 子对象分别提供 UI builder、引擎目录、内存目录别名和事件快捷方法。
log(message,level)、log_info/warn/error(message)、time()C：以上均有；P：log(message) 与 time()。time 为 epoch 秒数。
set_defaults(dict)、get_setting(key,default)、set_setting(key,value)、setting(key,default)C/P：默认设置、读取、写入；P 的 setting 为读取别名。C 的原生 typed 设置只接受 bool/int/finite float/string。
subscribe(topic,callback)、unsubscribe(token)、emit(topic,payload) / publish(topic,payload)C/P：订阅、取消、发送。C 的 subscribe 返 event_N token，事件 callback 收 payload；C 有 publish/emit 别名。P 的 callback 通常收 topic + payload。
subscribe_once(topic,callback)、on(topic,callback)、on_damage/on_heal/on_skill/on_boss/on_snapshot/on_encounter_finalized(callback)仅 P：一次性订阅及固定 topic 快捷入口，返回可注销订阅 token。C 未注册这些名称。
get_snapshot()、snapshot_value(path,default)、recent_events(limit=20,topic="")仅 P：读取状态快照、嵌套值和最近事件；C 根对象未注册。
register_ui_panel(id,meta,render,on_action)、request_redraw(id,reason)、open_window(id,w,h)C/P：注册面板后 render(payload) 返回声明式节点，action(action_id,payload) 返回结果；C 的 open_window 返回 {ok,status,panel_id}，不是 bool。
register_menu_category(name,icon,builder,priority)、register_menu_surface(id,descriptor,priority)、register_action_handler(callback)C/P：Entity 菜单 builder、菜单 surface 与动作回调；builder 返回行列表，command 或 handler 执行实际动作，需处理 stale/disabled 状态。
add_hotkey(id,cb,key,label) / register_hotkey(...)、unregister_hotkey(id)C：add_hotkey 与 register_hotkey 是别名，未提供独立注销方法；P：注册及注销均有。保存自己的 callback/token。
set_interval(cb,seconds)、set_timeout(cb,seconds)、clear_timer(token)、complete_timer(token)C/P：周期、一次性注册及取消；complete_timer 仅 P，停用时清理自己的 timer token。
notify(title,message,duration_s,kind)、toast(message)、dismiss_notify()C/P：通知、短提示与撤销；C notify 默认 duration_s=60、kind=plugin。
set_overlay(surface,spec)、clear_overlay(surface)C/P：surface 所有权归插件当前代；专用 8 MiB JSON 预算，明确给出 surface。
load_local(path)、ensure_requirements(install=True)C/P：插件根内 helper 与需求查询；C 的 install 入参忽略，.py 返回模块；跨语言 helper 仅允许有界 JSON-compatible 值/callable。
get_engine(name) / get(name)、register_engine(name,engine) / register(name,engine)、get_engine_method(name,method,fallback)、set_owner_attr(name,value)、owner_attr(name)仅 C：插件局部 EngineAccess 兼容入口；它不是 126 反射函数目录。P 使用 ctx.engine.get/call/require/register 或根方法 get_engine/require_engine/call_engine/register_engine。
engine_call(name,args,callback_channel)C/P：raw 反射调用；C 必须传 object args，成功返回 result，回调型槽无通用 callback facade；P 同时有 engine.list/on 与命名方法。
register_render_hook(surface,callback,priority)、unregister_render_hook(token)、register_data_source(id,meta,start,stop)仅 P：渲染 hook 与带生命周期 callback 的数据源；C 根对象未绑定。
register_parser_adapter/register_exporter/register_formatter/register_trigger_type/register_report_view/register_timer(id,metadata)仅 P：六类扩展描述符注册；C 根对象未绑定。
open_file(filters,title)、run_on_ui(callback)、register_thread(callback)、call_runtime(...)、open(...)仅 P：文件选择与有限 UI 调用；register_thread/call_runtime 是 no-op 兼容项，不表示完整 Python 线程/动态执行。
create_compositor_layer(name,w,h,…)、upload_compositor_frame(name,bytes,w,h)、set_compositor_layer_position/visible/input(...)、destroy_compositor_layer(name)仅 P：图层管理，真实显示仍由 compositor provider 负责。
set_compositor_layer_mmf_source(name,mmf)、set_compositor_layer_shared_texture_source(name,handle,w,h)、compositor_gpu_interop_available()、compositor_layer_shared_texture_active(name)C/P：查询或绑定共享帧源；C 根对象只注册这一组，不提供上一行的图层创建等接口。
compositor_display_refresh_hz()仅 P：查询子集宿主的显示刷新率。
