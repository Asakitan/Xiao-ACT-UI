01

SHARED CONTRACT

如何阅读本全集

此页列出完整插件清单字段、22 个声明式 UI 构造器、六组共 126 条 sdk_binding 引擎目录和七条运行路径的 ctx 对照；每种语言的调用语法、生命周期、准确的宿主实现及可运行示例见对应语言页。原生 SDK C ABI 与脚本 ctx facade 不同，C 函数不能直接当脚本方法调用。

反射引擎名称为 group.method（例如 mem.read_u64），命名包装一般将点变成下划线（ctx.engine.mem_read_u64(address)）；raw 调用传 {"name":"mem.read_u64","args":{"address":4096}}。底层 envelope 是 {"status":整数,"result":值}，不同宿主选择抛错或仅返回 result；engine.list() 返回带 name、args、available 的目录记录，available=false 表示当前 provider/slot 不可用。

binary 数据参数和结果用 *_b64 字段传 Base64；句柄/token 是无符号整数。需要回调的反射条目要求宿主提供对应 callback 通道，未绑定时不会假装成功；使用对应语言原生 ctx.register_ui_panel、ctx.register_menu_category 等回调 API 时不走反射目录的通用方法 ID。

PLUGIN.JSON

清单字段

字段类型与用法
id、name、version插件身份、显示名称和版本。ID 要在扫描根内唯一。
language、entry语言身份：python/lua/emma/angelscript/csharp；入口为插件根内文件，相应扩展名 .py/.lua/.emma/.as/.cs 或托管 .dll。
py_runtimeauto（缺省）、pymini 或 cpython；只适用于 Python。
cs_runtime、managed_typeauto（缺省）、csmini 或 coreclr；CoreCLR DLL 还需托管类型和 runtimeconfig。
enabled、permissions初始启用状态与权限 ID 列表；如 Lua require、反射 engine_access。
capabilities字符串能力 ID 或带 id/title/description/actions 的对象数组，供管理器展示。
settings_schema键→类型、default、description 的设置 schema；运行时 set_defaults 仅补未保存值。
platformmin_api_version、binds 等需求声明；显示/预检不等于实际实现保证。
locales、sao_menu本地化展示字段与菜单展示元数据；不会翻译脚本硬编码的文本。

方法返回 JSON-compatible 节点；下面括号内是位置参数顺序，动态语言可使用同名关键字。可用 ctx.ui.panel(...) 作为注册面板的 render 回调返回值；canvas/rgba_frame 可组成 overlay 文档节点。渲染路径还会做节点/深度/字节预算验证，构造成功不代表上屏成功。

builder 接口只定义节点结构，不拥有显示生命周期；面板渲染需注册 panel ID，覆盖层需以 surface 调用 set_overlay，同 surface 重绘在提交前保留旧图像；显式 clear_overlay(surface) 解除它。

SCRIPT CONTEXT

七执行路径的 ctx 接口对照

本表按真实宿主的注册表列出脚本根对象的方法（不含上文已逐项说明的 UI builder 和反射目录）。宿主标记：C 隔离 CPython、P pymini、L Lua、E Emma、A AngelScript、S csmini。托管 CoreCLR 由插件自行提供 managed facade，经 native sdk table 映射，具体声明见 C# 手册；它不是自动获得 csmini 全部方法。空缺代表该执行路径的根对象未注册此方法。

ctx 方法或属性运行模式 · 参数、返回与语义
plugin_id, path, web_path, assets_path, base_dir身份和路径只读属性；C 有上述全部及 get_plugin_id()/get_base_dir()；P/E/S 有前四项；L 只有 plugin_id/path；A 的 plugin_id 由 generic bindings 注册，另有 path/web_path/assets_path。
should_stop, owner, ui, event_bus, engine, mem子对象/属性：C 的 mem 是空 dict、engine 是 ctx 自身；P/S 的 mem 是反射内存 facade；A 的 mem 为独立 MemAccess；E 无 mem；L 仅 ui/engine。owner 按宿主类型不同，过期后不复用。
log(message[,level]), log_info/warn/error(message)日志：C/P/L/E/A/S 有 log；log_info 同时在 C/A 注册，log_warn/log_error 只在 C 根对象注册。
time()C/P/L/E/A/S → epoch 秒数；A 由 generic bindings 注册。
set_defaults(defaults)C/P/L/E/A/S → 补尚未保存的设置默认值；值必须可序列化，A 返回 bool。
get_setting(key,default), setting(key,default)读取设置，缺键用 default：全路径有 get_setting；P/L/E/A/S 有 setting 别名，C 根对象无该别名。
set_setting(key,value)C/P/L/E/A/S → 保存可序列化设置；C 直连 typed SDK 的 value 限 bool/int/float/string，A 返回 bool。
subscribe(topic,callback), subscribe_once(topic,callback)事件注册返回 token；C 只有 subscribe；P/L/E/A/S 两者都有；回调实参形状依宿主（payload 或 topic+payload），保存 token 供 unsubscribe。
unsubscribe(token), emit(topic,payload), publish(topic,payload)取消订阅、发送事件；C/L 有 publish/emit 别名；P/E/A/S 只注册 emit。C token 是 event_N 字符串。
on(topic,callback)P/E/A/S 绑定 topic 的兼容快捷方法；L/C 根对象没有该方法。
on_damage/on_heal/on_skill/on_boss/on_snapshot/on_encounter_finalized(callback)P/E/A/S 固定主题订阅快捷方法；各宿主 topic 名可能不同（如 A 的 on_snapshot 对应 act_snapshot）。
get_snapshot(), snapshot_value(path,default)P/L/E/A/S 读取当前状态快照与点路径字段；C 根对象未注册。A 的 snapshot_value 需 JSON addon。
recent_events(limit,topic)P/E/A/S 缺省 limit 20；L 缺省 64；C 未注册。返回事件记录数组。
register_ui_panel(id,metadata,render,on_action)C/P/L/E/A/S → 注册声明式面板与两个回调；render 接收 payload 并返回 UI spec，action 接收 action_id/payload。各语言返回 panel ID、bool 或 status 派生值。
request_redraw(surface,reason)C/P/L/E/A/S → 请求下一次渲染；reason 可省；C 可只传面板 ID。
set_overlay(surface,spec), clear_overlay(surface)C/P/L/E/A/S → owner-scoped overlay 新帧事务提交/显式移除；A 的 clear_overlay 虽有空字符串缺省声明，实际需要非空 surface。
register_render_hook(surface,callback,priority), unregister_render_hook(token)P/L/E/A/S → 注册/注销渲染 hook，默认 priority 0；C 根对象无这两个方法。
register_menu_category(name,icon,builder,priority)C/P/L/E/A/S → Entity/插件栏菜单 builder，返回行数组；行含 id/label/action_id，可携 command 回调、keep_menu_open 等。
register_menu_surface(id,descriptor,priority), register_action_handler(callback)C/P/L/E/A/S → 注册菜单面及带 (action_id,payload) 的动作回调。
register_hotkey(id,callback,default_key,label), unregister_hotkey(id)P/L/E/A/S 支持注册/注销；C 有 add_hotkey 及 register_hotkey 别名，但没有 unregister_hotkey；L 的热键 API 受 hotkey 权限门控。
register_parser_adapter/register_exporter/register_formatter/register_trigger_type/register_report_view/register_timer(id,metadata)P/E/A/S → 登记对应扩展描述符；C/L 未注册这些根方法。
register_data_source(id,metadata,start,stop)P/E/A/S → 绑定数据源的启动/停止回调；C/L 根对象无此入口，A 要求至少提供一个回调。
register_thread(callback), run_on_ui(callback)P/S 的 register_thread 不启动线程；E 同名也不启动线程。P/S/E 提供 run_on_ui，mini 为已实现的同步/one-shot 子集；C/L/A 根对象无。
set_interval(callback,seconds), set_timeout(callback,seconds), clear_timer(token)C/P/L/E/A/S → 周期/一次性定时器与注销；seconds 为正数；停用时显式清理持有的 token。S 另有 complete_timer(token)。
notify(title,message,duration_s,kind), dismiss_notify(), toast(message)C/P/L/E/A/S → 创建/关闭提示；C 的 notify 默认 duration 60 秒、kind plugin，C 的 dismiss_notify 不收参数。
open_file(filters,title,initial_dir,hwnd)P/L/E/A/S 提供本地文件选择；S 只使用 filters/title；C 根对象无。取消时返回空路径或 null，具体依宿主。
open_window(panel_id,width,height)C/P/L/E/A/S 打开注册面板；C 返回 {ok,status,panel_id} 而非 bool。
register_engine(name,engine), get_engine(name)C/P/L/E/A/S 插件局部引擎注册/查找；C 的 register/get 是 engine 兼容别名；L 需要 engine_access 权限；A 使用 get_engine(name, ?&out engine)。
require_engine(name), call_engine(name,method,args)P/E/S 提供 require/call；A 只有 require（out 参数）；C 可通过 get_engine_method 获取成员方法，L 无 require/call 根绑定。
engine_call(name,args)C/P/L/E/A/S → 反射目录 raw 调用；C 返回解包 result 且错误抛异常，E 返回完整 envelope，A 传 JSON 字符串并返回 JSON 字符串，L 需 engine_access。
load_local(relative_path), ensure_requirements(install)C/P/L/E/A/S → 限定插件根内 helper / 获取需求报告；C 的 install 参数会被忽略；A 另有 load_local_path(relative_path)。
create_compositor_layer(name,w,h,…), destroy_compositor_layer(name)P/L/E/A/S 原生图层生命周期；C 根对象未注册创建/销毁方法。
upload_compositor_frame(name,bytes,w,h), set_compositor_layer_position(name,x,y), set_compositor_layer_visible(name,visible), set_compositor_layer_input(name,…)P/L/E/A/S 图层帧、坐标、显隐及输入设置；具体 bytes 类型随语言转换。
set_compositor_layer_mmf_source(name,mmf), set_compositor_layer_shared_texture_source(name,handle,w,h), compositor_gpu_interop_available(), compositor_layer_shared_texture_active(name)C/P/L/E/A/S 暴露共享来源和查询；真实可用性由 compositor provider 决定。
compositor_display_refresh_hz()P/S 子集路径有此方法；S 固定回 0.0，不能用作显示器实测。
call_runtime(...), open(...)P/S 的 call_runtime 是无操作兼容入口，S 的 open 抛 NotSupportedException；不要将它们视为完整 Python/.NET 的通用运行库。

子对象差异：P/S 的 ctx.event_bus 有 subscribe/subscribe_once/unsubscribe/emit/on，ctx.mem 是共享引擎目录的 mem 子集；E 的 event_bus 含 snapshot/recent_events，engine 含 get/require/register/has/list/on；A 的 MemAccess 是独立 v1 facade（attach/detach/module_base/read_u32/read_u64/read/read_ptr_chain/enumerate_modules），需要对应 addon。C 的 ctx.engine 即 ctx 自身，ctx.mem 为空 dict。

MANIFEST REFERENCE

全部 plugin.json 字段

以下是当前 loader 解析的全部顶层字段；未知键被忽略。清单解析成功仍需通过 ID、entry 路径和 ABI 校验。原始 JSON 最大 1 MiB、深度 64、节点 16384、单个字符串/键 64 KiB、字符串合计 512 KiB；拒绝非法 UTF-8、NUL、超预算或越界路径。

字段类型、默认值、实际语义
idstring；1..128 字符，由字母/数字/下划线/短横线/点组成，不接受单独 . 或 ..；插件根内身份唯一。
name、version、descriptionstring；name 缺省 ID，version 缺省 0.1.0，description 为说明。
entrystring，相对插件根的入口；缺省依语言猜测 plugin.py/.lua/.emma/.as/.cs。拒绝绝对路径、父目录逃逸及指向根外文件。
language / engine / runtimestring，按前者优先读取；缺省从 entry 扩展名推断，再缺省 Python。支持 python/lua/emma/angelscript/csharp 与 loader 的现行兼容别名。
enabled、primary、hiddenbool，分别缺省 false、true、false；运行初始状态、主插件标志和目录隐藏状态。
py_runtime / runtime_hintstring；pymini/cpython/auto；只有 py_runtime 为空时读取 runtime_hint。
cs_runtimestring；csmini/coreclr/auto；.cs 不由宿主自动编译为 .NET DLL。
managed_type、runtimeconfigstring；托管 entry 的程序集限定类型和 runtimeconfig 路径，未提供类型时按 Plugin,<entry-stem> 推导；runtimeconfig 必须在插件根内。
requires、depsarray/object/标量，合并为依赖列表；runtime_features 数组规范化为 runtime_feature: 前缀。
permissions、game_idsstring 数组，保留非空 ID；权限决定如 require、engine_access 等宿主能力。
capabilities数组；字符串或对象，后者含 id（别名 capability_id）、title、description、route、render_hint、actions[]、payload_fields[]。
settings_schemaobject；每键值提取 type、description 和 default JSON。
hotkeysobject 或 array；支持 ID 与 default/default_key、label；仍需宿主实际注册动作。
sao_menu、overlay_layers任意 JSON 值，保留序列化元数据；不等于直接创建渲染资源。
locales / i18n / translationsobject，本地化元数据别名；脚本自有提示文案不会自动翻译。
platform、surfaceplatform object 保留原值，并提取 binds[] 与 surface；顶层 surface 只在 platform.surface 为空时回退。
min_width、min_height非负整数，缺省 0；初始布局提示。
mcpServers、chatProvidersJSON 原样保留，供需要的插件/编辑器扩展使用。
protected、native_entry、native_abi、abi_version受保护/native 插件字段；protected=true 必须有 native_entry，native_abi 必须为当前可接受的 sao_plugin_v1 或 sao_plugin_v2；abi_version 不得高于宿主支持值。脚本包通常不需要声明。
