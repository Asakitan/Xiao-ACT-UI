01

ANGELSCRIPT

AngelScript 插件 API

原生 AngelScript 编译器和强类型 PluginContext@；句柄用 @，传回 UI 的数据常用 dictionary@ 和 array<dictionary@>。

{"id":"my_as_plugin","name":"AS 示例","version":"1.0.0",
 "language":"angelscript","entry":"plugin.as","enabled":false,
 "permissions":[]}

入口 void on_load(PluginContext@ c) 把 ctx 保存为全局 handle；on_enable()、on_disable()、on_unload() 是可选 hook。on_unload() 清理自建资源并把持有的 ctx handle 置空。

02

CONTEXT

ctx 方法速查

用途调用
日志 / 设置ctx.log(msg)、ctx.log_info(msg)、ctx.time() 由 generic bindings 注册；设置为 ctx.set_defaults(dictionary)、ctx.get_setting(key, fallback)、ctx.set_setting(key, value)。
面板ctx.register_ui_panel(id, metadata, @render, @action)、ctx.open_window(id, width, height)、ctx.request_redraw(id, reason)
UI builderctx.ui.panel/section/row/kv/button；children 使用 array<dictionary@>
菜单 / 通知ctx.register_menu_category(title, icon, @builder, priority)、ctx.register_action_handler(@handler)、ctx.register_hotkey(…)、ctx.notify(title, text, seconds)
定时 / 覆盖层ctx.set_interval(…)、ctx.clear_timer(token)、ctx.set_overlay(surface, spec)、ctx.clear_overlay(surface)
模块 / 引擎ctx.load_local(path)、ctx.engine_call(name, args_json)（JSON 字符串）、ctx.engine_list()

逐项签名及宿主差异见 ctx 接口全集；反射函数与参数见 引擎目录。

03

QUICK START

面板 + 菜单示例

PluginContext@ ctx;
int count = 0;
void open_panel() { ctx.open_window("demo", 520, 360); }
array<dictionary@>@ build_menu() {
    dictionary@ item = {"id": "open", "action_id": "demo.open",
        "label": "打开面板", "command": @open_panel};
    return {item};
}
void on_load(PluginContext@ c) {
    @ctx = c;
    dictionary meta;
    meta["title"] = "AngelScript 示例";
    ctx.register_ui_panel("demo", meta, @render_panel, @on_action);
    ctx.register_menu_category("AS 示例", "AS", @build_menu, 40.0);
}
dictionary@ render_panel(dictionary@ payload) {
    array<dictionary@> children = {
        ctx.ui.kv("次数", tostring(count)),
        ctx.ui.button("增加", "add", "primary")};
    array<dictionary@> sections = {ctx.ui.section("状态", children)};
    return ctx.ui.panel("AS 示例", sections);
}
dictionary@ on_action(string action_id, dictionary@ payload) {
    if (action_id == "add") {
        count += 1;
        ctx.request_redraw("demo", "count_changed");
        return {"ok": true};
    }
    return {"ok": false};
}
void on_unload() { @ctx = null; }

完整的状态、菜单与热键参考：plugins/example_angelscript_plugin/plugin.as。

04

HELPERS & ENGINE

模块与边界

脚本按 section 直接编译，#include 不执行源码预处理；用 ctx.load_local("helpers/x.as") 加载同插件根内 helper。LocalModule 的 get/call 返回 json@，取标量前检查真实 JSON 类型。不同 helper 独立物理模块，不共享全局值。

ctx.engine_call("mem.read_u64", "{\"address\":4096}") 的第二参数为 JSON 字符串，返回 envelope JSON 字符串，调用方须解析并检查 status；ctx.engine_list() 返回目录 JSON 字符串。宿主另提供 sao_engine typed/raw 包装。回调、参数类型与可用性以目录/当前 provider 为准。

05

FULL TYPED SURFACE

全部 AngelScript ctx 接口

公开面由 as_generic_bindings.cpp 和 as_ctx_surface.cpp 共同注册；?&in 是动态输入，函数 handle 用 @fn。基础层提供 ctx.log(string)、ctx.log_info(string)、ctx.plugin_id、ctx.should_stop 和 ctx.time()。UI 构造器及 126 项反射参数分别见 UI、引擎目录。

成员签名、返回与使用
path,assets_path,web_path,engine,event_bus,ui,mem,ownerget_* 只读属性；engine/event_bus 返回 ctx handle，ui 返回 UiBuilder@，mem 返回 MemAccess@，owner 需要 dictionary addon。
subscribe(topic,callback)、subscribe_once(topic,callback)、on(topic,callback)、unsubscribe(int64 token)前三者返回 int64 token，取消返回 bool；回调经当前 plugin ctx 代际保活。
on_damage/on_heal/on_skill/on_boss/on_snapshot/on_encounter_finalized(callback)固定事件快捷订阅，返回 int64 token；on_snapshot 对应 act_snapshot。
emit(topic,payload=null)、get_snapshot()、snapshot_value(path,default=null)、recent_events(limit=20,topic="")发布事件、读取状态和事件列表；返回 bool/dictionary@/json@/array<dictionary>，部分依赖 JSON/array/dictionary addon。
get_setting(key,default=null) / setting(...)、set_setting(key,value)、set_defaults(defaults)设置读返回 json@、写/默认值返回 bool；set_defaults(dictionary@) 另有重载。
register_ui_panel(id,metadata,render,on_action)、request_redraw(surface="",reason="")面板 callback 与重绘返回 bool；render 应返回 dictionary@，action 接收 action_id/payload 并返回动作结果。
register_menu_category(name,icon,builder,priority=0)、register_menu_surface(id,descriptor,priority=0)、register_action_handler(handler)Entity 菜单及 action 回调注册均返回 bool，builder 通常返回 array<dictionary@>@。
register_render_hook(surface,callback,priority=0)、unregister_render_hook(token)返回 int64 hook token / bool；回调按宿主能力调用。
set_overlay(surface,spec)、clear_overlay(surface)返回 bool；clear 虽声明 surface=""，实际非空键才会清除。
register_hotkey(id,callback,default_key="",label="")、unregister_hotkey(id)绑定/注销热键，返回 bool。
register_parser_adapter/register_exporter/register_formatter/register_trigger_type/register_report_view/register_timer(id,metadata=null)六种扩展描述符，返回 bool；与真实周期 timer callback 分开。
register_data_source(id,metadata,start,stop)注册启停回调；start 或 stop 至少一个 callable，成功返回 bool。
register_engine(name,engine)、get_engine(name,?&out engine)、require_engine(name,?&out engine)插件内引擎句柄注册/取回，返回 bool 并写 out；并非反射 engine_call 的替身。
set_interval(callback,seconds)、set_timeout(callback,seconds)、clear_timer(token)前两者返回 string token，clear 返回 bool；seconds 必须大于零。
notify(title,message,duration_s=60,kind="plugin")、toast(message)、dismiss_notify()显示/撤销消息，返回 bool。
open_file(filters=null,title="",initial_dir="",hwnd=0)、open_window(panel_id,width,height)文件选择返回路径字符串（取消为空），打开已注册面板返回 bool。
load_local(path)、load_local_path(path)、ensure_requirements(install=true)返回 LocalModule@、绝对路径、json@；无源码级 include，helper 路径受插件根约束。
create_compositor_layer(name,w,h,x=0,y=0,z=140,click_through=true,high_fps=false,target_fps=0)返回 bool；创建后可上传帧或绑定共享源。
upload_compositor_frame(name,array<uint8>@ bytes,w,h)、set_compositor_layer_position(name,x,y)、set_compositor_layer_visible(name,visible)、destroy_compositor_layer(name)图层帧与生命周期操作，返回 bool。
set_compositor_layer_input(name,cursor_pos,mouse_button,cursor_leave,scroll)设置图层输入回调；对应参数均可省略为 null，返回 bool。
set_compositor_layer_mmf_source(name,mmf)、set_compositor_layer_shared_texture_source(name,handle,w,h)、compositor_gpu_interop_available()、compositor_layer_shared_texture_active(name)绑定来源和查询能力/激活状态，返回 bool。
engine_call(name,args_json)、engine_list()、engine_on(channel,callback)、engine_off(channel)前两者接收/返回 JSON 字符串；on/off 管理通用反射回调；另有生成的 sao_engine 命名 wrapper。
ctx.mem.attach/detach/module_base/read_u32/read_u64/read/read_ptr_chain/enumerate_modulesMemAccess@ 独立 typed 读 facade，需对应 array/dictionary addon；反射 mem.* 是另一条路径。

生成的 sao_engine namespace 接收显式 ctx；raw 返回 JSON envelope 字符串，可用宿主 JSON addon 解析并核对内层状态：

string catalog = sao_engine.list(ctx);
string raw = sao_engine.call_raw(ctx, "mem.read_u64", "{\"address\":4096}");
json@ reply = json_parse(raw);
if (reply is null || !reply.contains("status") || reply.get_int("status", -1) != 0)
    return;
