01

FIRST TIME

快速开始

第一次用按下面的顺序来。游戏里具体有哪些功能可用，取决于你装了哪些插件。

  1. 01

    启动

    双击安装目录里的 SaoAuto.exe。启动后屏幕右下角出现 NerveGear 悬浮按钮，系统托盘里多一个 SAO Auto 图标。

  2. 02

    打开菜单

    左键点悬浮按钮，或者按 HOME。主菜单里能进插件、面板和各个工具。

  3. 03

    启用插件

    在主菜单的"插件"页面，把你正在玩的游戏对应的插件启用。暂时用不上的可以保持停用，之后随时改。

  4. 04

    打开面板

    从主菜单或插件界面打开需要的面板。识别功能怎么启动，以插件界面上的提示为准。

i

配置文件里的 F 键

配置文件里可能还留着 F5 / F9 / F10 / F11 之类的旧默认值，那是兼容老配置用的，不一定生效。实际键位以"快捷键"面板里显示的为准。

04

PANELS & PLUGINS

面板和插件

插件提供功能，面板负责显示。一般的顺序是：先在插件里启用功能，再从菜单里打开对应的面板。

PLUGIN

插件

  • 玩哪个游戏就启用哪个游戏的插件。
  • 用不到的插件可以停用，之后随时能再启用。
  • 插件启用或停用后，它带的菜单项、面板和快捷键会跟着变化。
  • 插件的统一管理在主菜单的"插件"页面。
PANEL

面板

  • 面板从主菜单或插件界面打开。
  • 不需要的面板可以单独关掉。
  • 面板被游戏窗口挡住时，用面板自带的置顶或透明选项。
  • 面板里显示什么内容，由对应插件决定。
打开菜单→启用插件→打开面板→按插件提示启动识别

AI EDITOR

AI Editor

怎么打开

SAO 菜单›Tools›AI Editor (LLM)

SAO AI Editor 主面板

AI Editor 使用完整 HTML 编辑界面，将文件编辑、助手对话和设置放在一起。原有检查器、历史、日志和工具融入右侧工具与状态；宽度不足时上下排列。

编辑器与文件选择均显示在当前界面中。打开或另存为时可浏览目录、输入路径；覆盖已有文件需要明确确认。

  1. 第一次打开先进入“编辑器设置”，确认模型服务和基础偏好。
  2. 回到 SAO AI Editor 主面板，按当前界面选择需要的子面板。
  3. 按当前面板提供的对话、确认或提交控件操作；涉及文件时，先检查清楚再确认。
  4. 重要文件建议先备份；使用在线服务时，不要发送不方便外发的内容。

06

GPU HUNT

GPU Hunt · 场景辅助

怎么找到

SAO 菜单›Tools›AI Editor (LLM)›GPU Hunt 子面板

AI Editor 中的辅助子面板

GPU Hunt 在当前 Native AI Editor 提供时作为子面板出现，用于显示场景相关的识别状态。具体入口、状态和可用操作以面板当前显示为准。

  1. 先从 SAO 菜单 → Tools → AI Editor (LLM) 打开 SAO AI Editor。
  2. 在主面板中查找 GPU Hunt 子面板；没有该入口时，以当前界面为准。
  3. 按子面板显示的状态和提示操作，查看当前面板提供的结果。
  4. 场景或目标变化后，按子面板当前提供的刷新、重置或关闭提示处理。

结果使用

面板显示的结果以当前会话为准；切换场景或目标后，按当前界面提供的提示重新处理。本手册不展开内部工具操作。

08

TROUBLESHOOTING

常见问题

悬浮按钮不见了+

先按 INSERT 把它显示出来，再按 HOME 试试菜单能不能开。还不行就右键托盘图标确认 SAO Auto 是否还在运行；已经退出的话重新启动。

按快捷键没反应+

常见原因是和其他软件的全局键冲突。右键托盘图标 → "快捷键"，录入新的组合后查看卡片状态；失败会显示冲突或保存回滚提示。

面板打开了但内容为空+

先确认对应插件已启用、当前场景符合插件的要求。部分插件有自己的"启动识别"按钮，按插件界面上的提示操作。

面板被游戏窗口挡住+

大多数面板自带置顶或透明选项。也可以按 HOME 关掉主菜单，或关掉暂时不用的覆盖层。

插件界面和手册描述不一致+

本手册只讲平台通用的部分。插件随版本和游戏不同，菜单、面板、快捷键会有差异，以程序里实际显示的为准。

AI Editor 没有回复+

先检查模型的连接设置；使用在线服务时确认网络可用。还不行的话新开一个对话重试，单次提问不要塞入过多内容。

怀疑安装损坏，怎么排查+

先用 --safe-mode --log-level=debug 启动，确认核心功能正常并查看日志；如果核心文件缺失，重新安装或使用更新程序修复。

PRIVACY

隐私说明

01

数据保存在本机

配置和日志都存储在你的电脑上，是否保留、查看或删除由你决定。

02

联网范围清楚可控

正常启动可能进行许可校验和更新检查；使用在线 AI 时，还会发送你主动提交的内容。

03

手册只覆盖操作

本手册只包含用户能接触到的操作说明，不涉及实现细节和内部资料。

本手册的作用是说明界面上可用的功能怎么用，不负责解释技术实现。
