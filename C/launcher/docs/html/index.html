01

FIRST TIME

快速开始

第一次用按下面的顺序来。游戏里具体有哪些功能可用，取决于你装了哪些插件。

  1. 01

    启动

    双击安装目录里的 SaoAuto.exe。启动后屏幕左上角出现 NerveGear 悬浮按钮，右下角托盘里多一个 SAO Auto 图标。

  2. 02

    打开菜单

    左键点悬浮按钮，或者按 HOME。主菜单里能进插件、面板和各个工具。

  3. 03

    启用插件

    在主菜单的"插件"页面，把你正在玩的游戏对应的插件启用。暂时用不上的可以保持停用，之后随时改。

  4. 04

    打开面板

    从主菜单或插件界面打开需要的面板。识别功能怎么启动，以插件界面上的提示为准。

i

建议先用默认键位熟悉一下。需要改键：右键托盘图标 → "快捷键"。

04

PANELS & PLUGINS

面板和插件

插件提供功能，面板负责显示。一般的顺序是：先在插件里启用功能，再从菜单里打开对应的面板。

PLUGIN

插件

  • 玩哪个游戏就启用哪个游戏的插件。
  • 用不到的插件可以停用，之后随时能再启用。
  • 插件启用或停用后，它带的菜单项、面板和快捷键会跟着变化。
  • 插件的统一管理在主菜单的"插件"页面。
PANEL

面板

  • 面板从主菜单或插件界面打开。
  • 不需要的面板可以单独关掉。
  • 面板被游戏窗口挡住时，用面板自带的置顶或透明选项。
  • 面板里显示什么内容，由对应插件决定。
打开菜单→启用插件→打开面板→按插件提示启动识别
05

AI EDITOR

AI Editor

怎么打开

SAO 菜单›ACT›AI Editor (LLM)

内置的 AI 对话编辑器

AI Editor 分两部分：左边是文件编辑区，右边是 AI 对话区。第一次用需要先在设置里配置模型服务，之后就可以打开文件、在对话区提问或让它改代码。

  1. 第一次打开先进设置，配置要用的模型服务。
  2. 选好模型和对话模式，确认当前打开的工作区。
  3. 在对话框里描述要做什么；涉及改文件时，先检查它列出的改动再确认。
  4. 重要文件建议先备份；使用在线服务时，不要发送不方便外发的内容。

GPU HUNT

GPU Hunt · 找游戏相机和骨骼

怎么打开

SAO 菜单›工具›GPU Hunt

输入 PID，自动定位相机矩阵和骨骼数据

GPU Hunt 是一个独立小工具，用来从游戏显存的上传堆里读出当前帧的相机 view × projection 矩阵和骨骼坐标。整个过程不注入游戏进程，也不 hook 游戏。

  1. 在面板顶部的输入框填游戏进程的 PID（任务管理器 → "详细信息"里可以看到）。
  2. 点 Attach，状态变成 attached；再把 Auto Tick: OFF 点成 ON，让它以 60Hz 运行。
  3. 状态变成 locked 表示锁定成功，矩阵和骨骼坐标会显示在面板上。游戏正在渲染 3D 画面时，一般几秒内就能锁定。
  4. 切场景、换地图或游戏重启后，点 Invalidate 重新定位；不用了点 Detach。

工作原理

  • 先找上传堆：面板左下会列出所有 PAGE_WRITECOMBINE + MEM_COMMIT + MEM_PRIVATE 内存页，这是 D3D12 上传堆的特征，列表按分数排序。
  • 识别矩阵：透视投影矩阵有固定规律（m[3][3]≈0、|m[2][3]|≈1），先扫出候选，再用连续 30 帧对比锁定唯一解。
  • 识别骨骼：同时尝试 Vec3 数组（UE5 Skin Cache）和 4×3 矩阵数组（传统 CBV）两种排布，用正交基特征区分。
  • 锁定后开销很小：每帧只读 64 字节（4×4 float 矩阵）；骨骼默认每秒刷新一次。

与 AI Editor / 脚本的联动

GPU Hunt 的操作通过 gpuHunt.* 注册进了 AI Editor，也通过 AngelScript 的 gpu_hunt 命名空间暴露给脚本。面板、AI、脚本操作的是同一个 tracker。

COMMAND LINE

启动参数

日常使用直接双击 SaoAuto.exe 即可。下面这些参数主要用于排障，在命令行里运行 --help 也能看到同样的列表。

参数类别说明
--safe-mode常规不加载插件和 RT I/O，只启动核心界面，排查问题时先用它
--config=<path>常规指定用哪个配置文件，默认用安装目录下的
--log-level=<lvl>常规日志级别：trace / debug / info / warn / error / critical
--version / -v常规显示版本号后退出
--help / -h常规显示帮助后退出
--rt-io-operator诊断跑完整的 HYPERVISOR RT I/O 链路（R5 必选）
--rt-io-preflight-only诊断只做一次只读预检，做完就退出
--rt-io-input-checks诊断附加鼠标零点和 F24 键 down/up 检测
--rt-io-r5-check诊断输出 R5 细节（仅诊断；严格链路里 R5 本来就必选）
--rt-io-mf-check诊断附加 MF 回退诊断
--rt-io-exit-after-validation诊断验证完就退出，不进主循环
--rt-io-status-page诊断就算开着 --rt-io-operator，也保留 helper 的 F12 状态页
i
常用组合

怀疑程序异常：SaoAuto.exe --safe-mode --log-level=debug。只想确认 RT I/O 环境是否正常：--rt-io-preflight-only，全程只读，不改动系统。

08

TROUBLESHOOTING

常见问题

悬浮按钮不见了+

先按 INSERT 把它显示出来，再按 HOME 试试菜单能不能开。还不行就右键托盘图标确认 SAO Auto 是否还在运行；已经退出的话重新启动。

按快捷键没反应+

常见原因是和游戏或其他软件的全局键冲突。右键托盘图标 → "快捷键"，里面能看到当前生效的键位，重新绑定后保存。

面板打开了但内容为空+

先确认对应插件已启用、当前场景符合插件的要求。部分插件有自己的"启动识别"按钮，按插件界面上的提示操作。

面板被游戏窗口挡住+

大多数面板自带置顶或透明选项。也可以按 HOME 关掉主菜单，或关掉暂时不用的覆盖层。

插件界面和手册描述不一致+

本手册只讲平台通用的部分。插件随版本和游戏不同，菜单、面板、快捷键会有差异，以程序里实际显示的为准。

AI Editor 没有回复+

先检查模型的连接设置；使用在线服务时确认网络可用。还不行的话新开一个对话重试，单次提问不要塞入过多内容。

怀疑安装损坏，怎么排查+

先用 --safe-mode 启动，确认核心功能正常；要验证 RT I/O 环境就运行 --rt-io-preflight-only，只读操作，不会改动系统。

PRIVACY

隐私说明

01

数据保存在本机

配置和日志都存储在你的电脑上，是否保留、查看或删除由你决定。

02

发送内容由你决定

使用在线 AI 服务时，只有你主动提交的内容会被发出；各服务如何处理数据，以其隐私政策为准。

03

手册只覆盖操作

本手册只包含用户能接触到的操作说明，不涉及实现细节和内部资料。

本手册的作用是说明界面上可用的功能怎么用，不负责解释技术实现。
