01

FIRST TIME

快速开始

第一次用按下面的顺序来。游戏里具体有哪些功能可用，取决于你装了哪些插件。

  1. 01

    启动

    双击安装目录里的 SaoAuto.exe。启动后屏幕左上角出现 NerveGear 悬浮按钮，右下角托盘里多一个 SAO Auto 图标。

  2. 02

    打开菜单

    左键点悬浮按钮，或者按 HOME。主菜单里能进插件、面板和各个工具。

  3. 03

    启用插件

    在主菜单的"插件"页面，把你正在玩的游戏对应的插件启用。暂时用不上的可以保持停用，之后随时改。

  4. 04

    打开面板

    从主菜单或插件界面打开需要的面板。识别功能怎么启动，以插件界面上的提示为准。

i

04

PANELS & PLUGINS

面板和插件

插件提供功能，面板负责显示。一般的顺序是：先在插件里启用功能，再从菜单里打开对应的面板。

PLUGIN

插件

  • 玩哪个游戏就启用哪个游戏的插件。
  • 用不到的插件可以停用，之后随时能再启用。
  • 插件启用或停用后，它带的菜单项、面板和快捷键会跟着变化。
  • 插件的统一管理在主菜单的"插件"页面。
PANEL

面板

  • 面板从主菜单或插件界面打开。
  • 不需要的面板可以单独关掉。
  • 面板被游戏窗口挡住时，用面板自带的置顶或透明选项。
  • 面板里显示什么内容，由对应插件决定。
打开菜单→启用插件→打开面板→按插件提示启动识别
05

AI EDITOR

AI Editor

怎么打开

SAO 菜单›ACT›AI Editor (LLM)

内置的 AI 对话编辑器

AI Editor 分两部分：左边是文件编辑区，右边是 AI 对话区。第一次用需要先在设置里配置模型服务，之后就可以打开文件、在对话区提问或让它改代码。

  1. 第一次打开先进设置，配置要用的模型服务。
  2. 选好模型和对话模式，确认当前打开的工作区。
  3. 在对话框里描述要做什么；涉及改文件时，先检查它列出的改动再确认。
  4. 重要文件建议先备份；使用在线服务时，不要发送不方便外发的内容。

GPU HUNT

GPU Hunt · 找游戏相机和骨骼

怎么打开

SAO 菜单›工具›GPU Hunt

输入 PID，自动定位相机矩阵和骨骼数据

GPU Hunt 是一个独立小工具，用来定位当前场景的相机与骨骼数据，并把结果集中显示在面板上。

  1. 在面板顶部的输入框填游戏进程的 PID（任务管理器 → "详细信息"里可以看到）。
  2. 点 Attach，状态变成 attached；再把 Auto Tick: OFF 点成 ON，让它以 60Hz 运行。
  3. 状态变成 locked 表示锁定成功，矩阵和骨骼坐标会显示在面板上。游戏正在渲染 3D 画面时，一般几秒内就能锁定。
  4. 切场景、换地图或游戏重启后，点 Invalidate 重新定位；不用了点 Detach。

结果使用

锁定后，面板会持续显示场景状态与已识别对象。AI Editor 和兼容脚本可以使用同一份会话结果；切换场景后按上面的步骤重新定位即可。

参数类别说明

08

TROUBLESHOOTING

常见问题

悬浮按钮不见了+

先按 INSERT 把它显示出来，再按 HOME 试试菜单能不能开。还不行就右键托盘图标确认 SAO Auto 是否还在运行；已经退出的话重新启动。

按快捷键没反应+

常见原因是和游戏或其他软件的全局键冲突。右键托盘图标 → "快捷键"，里面能看到当前生效的键位，重新绑定后保存。

面板打开了但内容为空+

先确认对应插件已启用、当前场景符合插件的要求。部分插件有自己的"启动识别"按钮，按插件界面上的提示操作。

面板被游戏窗口挡住+

大多数面板自带置顶或透明选项。也可以按 HOME 关掉主菜单，或关掉暂时不用的覆盖层。

插件界面和手册描述不一致+

本手册只讲平台通用的部分。插件随版本和游戏不同，菜单、面板、快捷键会有差异，以程序里实际显示的为准。

AI Editor 没有回复+

先检查模型的连接设置；使用在线服务时确认网络可用。还不行的话新开一个对话重试，单次提问不要塞入过多内容。

怀疑安装损坏，怎么排查+

先用 --safe-mode --log-level=debug 启动，确认核心功能正常并查看日志；如果核心文件缺失，重新安装或使用更新程序修复。

PRIVACY

隐私说明

01

数据保存在本机

配置和日志都存储在你的电脑上，是否保留、查看或删除由你决定。

02

联网范围清楚可控

正常启动可能进行许可校验和更新检查；使用在线 AI 时，还会发送你主动提交的内容。

03

手册只覆盖操作

本手册只包含用户能接触到的操作说明，不涉及实现细节和内部资料。

本手册的作用是说明界面上可用的功能怎么用，不负责解释技术实现。
