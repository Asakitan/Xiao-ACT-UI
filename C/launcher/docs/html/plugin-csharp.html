C#

C# 插件 API

language: "csharp" 可选 C++ 实现的 csmini 源码子集，或预编译 .NET DLL 的 coreclr；二者执行方式与可用运行库不同。

原生 csmini

entry: "plugin.cs"、cs_runtime: "csmini"。类 Plugin 的静态方法提供生命周期，无需 .NET；只执行解析器支持的 C# 子集。

托管 CoreCLR

将编译好的 DLL、匹配的 .runtimeconfig.json 和依赖放入插件包。清单声明 cs_runtime: "coreclr" 和 managed_type，加载时按需调用 hostfxr。

{"id":"my_csharp_plugin","name":"C# 示例","version":"1.0.0",
 "language":"csharp","entry":"plugin.cs","cs_runtime":"csmini",
 "enabled":false,"permissions":[]}
02

CONTEXT

csmini PluginContext 方法

用途调用
日志 / 设置ctx.log(msg)、ctx.set_defaults(dict)、ctx.get_setting(key, fallback)、ctx.set_setting(key, value)
面板 / redrawctx.register_ui_panel(id, metadata, Render, OnAction)、ctx.open_window(id, w, h)、ctx.request_redraw(id, reason)
构造器ctx.ui.panel/section/row/kv/button；传入 object[] 或宿主支持的集合
菜单 / 通知ctx.register_menu_category(title, icon, BuildMenu, priority)、ctx.register_action_handler(HandleAction)、ctx.notify(title, text, seconds)
计时 / 叠层ctx.set_interval(…)、ctx.clear_timer(token)、ctx.set_overlay(surface, spec)、ctx.clear_overlay(surface)
引擎（仅 csmini）ctx.engine_call(name, args)、ctx.engine.list()、ctx.engine.mem_read_u64(address)（由当前目录/provider 决定）。CoreCLR 的托管 facade 见下方独立章节。

csmini 类静态 hook 为 OnLoad(PluginContext ctx)、OnEnable()、OnDisable()、OnUnload()；OnUnload() 返回 false 可以否决卸载。

03

QUICK START

csmini 面板示例

using System.Collections.Generic;
public class Plugin {
    private static dynamic _ctx;
    private static int count = 0;
    public static void OnLoad(PluginContext ctx) {
        _ctx = ctx;
        var meta = new Dictionary<string, object>();
        meta["title"] = "C# 示例";
        ctx.register_ui_panel("demo", meta, Render, OnAction);
        ctx.register_action_handler(HandleAction);
        ctx.register_menu_category("C# 示例", "C#", BuildMenu, 40.0);
    }
    public static object BuildMenu() {
        var item = new Dictionary<string, object>();
        item["id"] = "open";
        item["action_id"] = "demo.open";
        item["label"] = "打开面板";
        return new object[] { item };
    }
    public static object Render(object payload) {
        return _ctx.ui.panel("C# 示例", new object[] {
            _ctx.ui.section("状态", new object[] {
                _ctx.ui.kv("次数", count.ToString()),
                _ctx.ui.button("增加", "add", "primary") }) });
    }
    public static object OnAction(string actionId, object payload) {
        if (actionId == "add") {
            count += 1;
            _ctx.request_redraw("demo", "count_changed");
        }
        var result = new Dictionary<string, object>();
        result["ok"] = actionId == "add";
        return result;
    }
    public static object HandleAction(string actionId, object payload) {
        if (actionId == "demo.open") _ctx.open_window("demo", 520, 360);
        var result = new Dictionary<string, object>();
        result["ok"] = actionId == "demo.open";
        return result;
    }
    public static bool OnUnload() { return true; }
}

更多菜单、设置与通知用法见活动包 plugins/example_csharp_plugin/plugin.cs。

04

CORECLR & LIMITS

预编译与兼容边界

{"id":"managed_demo","name":"Managed Demo","version":"1.0.0",
 "language":"csharp","entry":"prebuilt/plugin.dll",
 "cs_runtime":"coreclr","managed_type":"PluginEntry,plugin",
 "enabled":false}

托管路径需要同名 prebuilt/plugin.runtimeconfig.json 和有效 .NET 运行库；宿主不会从 plugin.cs 编译 DLL。完整 SDK 映射参考 plugins/script_cutegirl_csharp/plugin_entry.cs；托管 entry 的静态入口 ABI 不等于 csmini 类 hook，按对应 managed shim 实现。

csmini 的 LINQ、Task/ValueTask、Guid 为有界实现；Task 为同步立即值，System.IO/Net/Threading、P/Invoke、unsafe、ref/out/in、跨文件 partial 及任意托管库需要 CoreCLR。auto 对源码做无执行子集预检，子集外返回明确不支持状态，不会自动源编译后再执行。

05

CSMINI API

csmini 全部 ctx 接口

csmini 从同一 ctx_builder 注册成员；方法名不区分大小写，脚本参数主要按位置传入。ctx.ui 实现 22 个构造器，ctx.engine 注册 126 项反射目录；下表是其他全部根成员。

名称参数、返回与语义
plugin_id,path,web_path,assets_path,should_stop,owner,ui,event_bus,engine,mem身份、路径和子对象；owner 为插件 ID，mem 为反射内存 facade，event_bus 有 subscribe/subscribe_once/unsubscribe/emit/on。
log(msg)、time()、get_setting(key,default) / setting(...)、set_setting(key,value)、set_defaults(map)日志、epoch 秒、设置读取/写入及默认值。
subscribe(topic,fn)、subscribe_once(topic,fn)、unsubscribe(token)、emit(topic,payload)持续/一次事件订阅、解除和发布；保留返回的 token。
on(topic,fn)、on_damage/on_heal/on_skill/on_boss/on_snapshot/on_encounter_finalized(fn)事件快捷订阅或 decorator 风格写法。
get_snapshot()、snapshot_value(path,default)、recent_events(limit=20,topic="")状态快照、路径值及事件序列。
register_ui_panel(id,meta,render,action)、request_redraw(surface,reason)、open_window(id,w,h)声明式 panel 生命周期、重绘与打开窗口；render(payload) 返回 UI spec，action(id,payload) 返回动作结果。
register_menu_category(name,icon,builder,priority)、register_menu_surface(id,descriptor,priority)、register_action_handler(fn)原生 Entity/插件栏菜单及回调，参考本页可运行示例。
register_render_hook(surface,fn,priority)、unregister_render_hook(token)、set_overlay(surface,spec)、clear_overlay(surface)渲染 hook 与 surface-keyed overlay；替换失败保持旧帧，专用 8 MiB spec 预算。
register_hotkey(id,fn,default_key,label)、unregister_hotkey(id)注册和注销插件热键。
register_parser_adapter/register_exporter/register_formatter/register_trigger_type/register_report_view/register_timer(id,metadata)六类扩展描述符；不等于下面的周期 timer。
register_data_source(id,metadata,start,stop)、register_engine(name,engine)绑定数据源的启动/停止回调；注册插件局部引擎对象。
get_engine(name)、require_engine(name)、call_engine(name,method,args)、engine_call(name,args)插件内 engine 查找、必需查找、调用及原生目录 raw 调用；ctx.engine 还含 get/call/require/register/list/on 与命名目录函数，ctx.mem 镜像 mem.*。
set_interval(fn,seconds)、set_timeout(fn,seconds)、clear_timer(token)、complete_timer(token)、run_on_ui(fn)周期/一次性 timer、注销/完成与已实现的有限 UI 调度；并非完整多线程 task scheduler。
notify(title,msg,duration_s,kind)、toast(msg)、dismiss_notify()通知、短提示和清除。
open_file(filters,title)、load_local(path)、ensure_requirements(install)文件选择、插件根 helper、需求报告；register_thread(fn) 与 call_runtime(...) 为无操作兼容项，open(...) 抛 NotSupportedException。
create_compositor_layer(name,w,h,…)、upload_compositor_frame(name,bytes,w,h)、set_compositor_layer_position(name,x,y)、set_compositor_layer_visible(name,visible)、set_compositor_layer_input(name,…)、destroy_compositor_layer(name)图层创建、帧上传、位置/可见/输入与销毁。
set_compositor_layer_mmf_source(name,mmf)、set_compositor_layer_shared_texture_source(name,handle,w,h)、compositor_gpu_interop_available()、compositor_layer_shared_texture_active(name)、compositor_display_refresh_hz()共享帧源与可用状态；csmini 当前显示刷新率固定返回 0.0，别当成实测显示器值。
06

MANAGED SDK

当前 CoreCLR 托管 facade

CoreCLR 宿主加载预编译程序集；托管 PluginContext 的具体 public 方法由插件随包实现。当前活动 plugins/script_cutegirl_csharp/plugin_entry.cs 的 PluginEntry.SaoCtx 是可参考的真实实现，不是任何托管插件都自动得到 csmini 表。它通过版本化 C ABI table 调用宿主；插件作者在自己的 managed shim 中实现 facade。

SaoCtx public 成员参数、返回与语义
path,plugin_id,should_stop,ui只读路径/身份、bool 停止状态、SaoUi 构造器对象。
log(params object[] args)、get_setting(key,fallback=null) / setting(...)、set_setting(key,value)、set_defaults(defaults)日志与基础 JSON 设置；get 返回 object，set/default 为 void。
toast(message)、notify(message)本 shim 的 notify(message) 只是 toast 别名，均返回 void；不接受 title/duration。
set_interval(Delegate fn,double seconds)、set_timeout(Delegate fn,double seconds)、clear_timer(object token)timer 返回 object（实际字符串 token），callback 必须可转 Func<object>，clear 为 void。
register_ui_panel(id,meta,render=null,action=null)返回 native JSON object；render(payload) → UI spec，action(actionKey,payload) → result。
register_action_handler(handler)、register_menu_category(name,icon,builder,priority)handler(actionId,payload) 返回结果；builder() 产出行，行的 command 为 Action；托管 shim 管理菜单树与结果提交。
request_redraw(surface="")、open_file(filters,title,initial_dir,hwnd)、open_window(panelId,width=0,height=0)重绘、文件选择及面板打开；无 surface 时按已注册 panel 遍历；取消文件选择为 null。
create_compositor_layer(name,w,h,x,y,z,clickThrough,highFps=false,targetFps=0)、upload_compositor_frame(name,byte[] bgra,w,h)、set_compositor_layer_position(name,x,y)、set_compositor_layer_visible(name,visible)、destroy_compositor_layer(name)图层、BGRA 帧与几何/显隐/销毁；上传检查 32 MiB 上限。
set_compositor_layer_mmf_source(name,mmfName)、set_compositor_layer_shared_texture_source(name,handle,w,h)、compositor_gpu_interop_available()、compositor_layer_shared_texture_active(name)、compositor_display_refresh_hz()共享源与 GPU 查询，返回类型分别为 void / void / bool / bool / int。
prompt(title,current)、Dispose()阻塞 prompt 返回文字或 null；Dispose 清理托管 facade 自己的 panel 集合。

这个托管 shim 的 SaoUi 实际公开 panel,section,row,kv,button,text,title,divider,spacer,badge,input,table,bar,slider,Build(method,args)（含重载），并非自动暴露全部 22 个 UI builder；其余底层构造器可经 Build 调用。底层 cs_managed_sdk_table 还含 dispatch、log、register/get_engine、entity provider、ui_build、prompt 等 ABI 槽位；槽位存在不等于本托管 facade 声明了同名 public 方法。
